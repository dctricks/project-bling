# Project BLING — Sales Tracker

A beginner-friendly Python sales management application built
to practice programming, database management, and data reporting.

## Features

- Add new sales
- View total revenue and average sale
- Search sales by ID
- View complete sales history
- Update existing sales
- Delete sales with confirmation
- Generate daily sales reports
- Export sales records to CSV
- Store records persistently using SQLite

## Technologies

- Python 3
- SQLite3
- CSV
- Python standard library

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run:

   python bling_db.py

## Project Purpose

Project BLING is a hands-on programming project
developed to build practical Python skills.

It demonstrates functions, loops, input validation,
SQL queries, database operations, and CSV exports.
